Китайские API-платформы для покупки API к ИИ-моделям

Дата проверки URL: 23 июня 2026.

Формат: ранжированный список без дублей. Китайские иероглифы в названиях оставлены, потому что по ним проще искать платформы в китайских источниках.

Цены ниже - ориентиры. В relay API они меняются быстро: разные каналы, разные группы, скидки, кэш, подписки, скрытые коэффициенты. Перед оплатой нужно заново открыть личный кабинет и проверить цену, канал, списания, лимиты, возврат, документы и риск подмены модели.

Правило: не пополнять крупно. Сначала ¥1-¥10. Потом 2-3 дня тестов на реальных задачах. Только после этого выбирать основную платформу.

№ 1. ChatAnywhere

https://api.chatanywhere.tech

Документация: https://docs.chatanywhere.tech

Цены: в документации указано gpt-5.5 - 0.035 / 0.21 за 1K tokens, gpt-5.5-ca - 0.02 / 0.12 за 1K tokens. Важно: это цена за 1K, не за 1M.

Крупная китайская relay-платформа. Поддерживает GPT, Claude, Gemini, DeepSeek, Qwen, Kimi, MiniMax и другие модели. Подключение стандартное: меняется base_url и api_key. Хороша для дешевого теста, учебных задач и личного вайбкодинга. Для чувствительных данных - не основной вариант.

Очень дешевый китайский API-релей с фокусом на GPT и Claude. Интересен ценой, но без подтвержденного домена его нельзя ставить как основной вариант. Только поиск через китайские каталоги, минимальное пополнение и ручная проверка качества.

Практическое правило тестирования

1. Открыть 3-5 платформ из верхней части списка. 2. Пополнить минимально: ¥1-¥10. 3. Прогнать один и тот же набор задач: Codex, Claude Code, длинный контекст, несколько повторов, один тяжелый рефакторинг. 4. Сравнить цену, скорость, стабильность, списания, качество модели, ошибки, поддержку Prompt Cache и риск подмены. 5. Основную платформу выбирать только после нескольких дней реальной нагрузки.

Предупреждение

Все relay API - посредники. Запросы проходят через стороннюю инфраструктуру. Для личного кода и тестов это может быть приемлемо. Для клиентских данных, паролей, приватных репозиториев, финансовых документов и коммерческих секретов лучше использовать официальный API, корпоративный контракт или собственную инфраструктуру.
